| 类别    | 具体机制                          | 主要特点             |
| ----- | ----------------------------- | ---------------- |
| 字节流通信 | 匿名管道、FIFO管道、Socket              | 像读写文件一样传输字节      |
| 消息通信  | System V/POSIX消息队列            | 以一条条消息为单位        |
| 共享内存  | System V共享内存、POSIX共享内存、`mmap` | 速度快，但需要额外同步      |
| 同步机制  | 信号量、互斥量、条件变量、读写锁              | 协调访问，一般不负责传输业务数据 |
| 异步通知  | 信号                            | 通知某个事件发生，携带信息有限  |
| 文件同步  | 文件锁                           | 协调多个进程访问文件       |


System V和POSIX是两套不同来源、不同接口风格的Unix/Linux编程规范
现在主要学习POSIX
